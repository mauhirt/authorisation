# R1 — threshold-reform attempts, 1986/1990–2026 (appendix compilation)

**Status: every row `secondary_unverified`** — compiled 2026-08-24 from the web
sources listed per row (news, Ballotpedia, LAO, state legislative records read
through secondary reporting). No row enters an estimate; the purpose is the
persistence-mechanism prediction: **reform attempts concentrate in no-exit
sectors (schools), and the one recent non-school attempt failed.** Owner
verification against primary legislative records required before citation.

## Read against the mechanism
1. **Sector concentration is as predicted.** Of the threshold-lowering attempts
   since 1990, every one but CA Prop 5 (2024) targets SCHOOLS — the sector the
   menu matrix (M1) shows holding the poorest exit menu (29.8% non-voted $) and
   D4 shows the rule binding hardest. Where exits exist (general-purpose
   governments at 80% non-voted $), nobody spends $30M to lower the bar.
2. **The one non-school attempt failed** (Prop 5: housing/infrastructure, 2024)
   while the school-only version passed in the same state (Prop 39, 2000) — and
   Prop 39's coalition was elite-financed, bipartisan-fronted, and sector-scoped.
3. **Reform also runs the other way** (OR 47/50 tightening; TX 2019
   ballot-structure regulation) — the agenda margin is contested terrain in both
   directions, matching E-series evidence that the agenda absorbs moderate bars.
4. In-panel hooks: Prop 39 is the W1 wedge's rule variation; TX HB 3 is the
   TX-2019 unbundling event in AGENDA_RESULTS.
