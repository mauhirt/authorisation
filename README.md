# Who Must Agree — analysis repository

Analysis and paper repository for "Who Must Agree" (bond authorisation rules
as coalition requirements). Conventions: every number in a paper document
traces to a committed script's RESULTS file; anomalies are flagged, never
silently fixed; provenance travels with every external input.

**VERSION PIN: the conference draft is frozen on auth corpus package v3**
(`inputs/corpus/`, meta branch effd25b034, verified 2026-08-24 — see
`analysis/ANALYSIS_REVIEW.md` §5b). Package v4 and the B5 rerun land in the
journal revision only.

- `paper/EMPIRICS_DRAFT.md` — the empirical sections (+ online appendix,
  variable inventory).
- `analysis/` — scripts, RESULTS files, caches; `FINDINGS.md` is the
  numbers-locked findings record; `ANALYSIS_REVIEW.md` the adversarial review.
- `inputs/` — corpus package, election registries, GFD compacts, rules panel
  (PRELIMINARY pass-1; pass-2 worklist in `analysis/RULES_PASS2_WORKLIST.md`),
  external panels (each with PROVENANCE).
